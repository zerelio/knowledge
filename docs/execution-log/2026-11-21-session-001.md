## Decisions Made

| Decision | Rationale |
|----------|-----------|
| Modular monolith | 4 of 5 microservices are too small to justify separate processes |
| PostgreSQL unified storage | Single DB reduces operational complexity; AGE + pgvector cover graph + vector needs |
| Apache-2.0 license | Patent protection, enterprise adoption, no GPL dependency conflicts |
| Ed25519 for JWTs | Asymmetric signing prevents forgery even if verifiers compromised |
| Argon2id for passwords | Memory-hard, GPU/ASIC resistant; replaces SHA-256 |
| LPG over RDF | Metadata-rich edges essential for infrastructure domain |
